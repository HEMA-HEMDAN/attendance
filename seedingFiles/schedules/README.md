The current schedule master-data source is the embedded transcription in `apps/accounts/management/commands/pasted_schedule.py`, based on the complete timetable transcription supplied by the user. The old `scadule.xlsx` is deleted and is not read. The embedded configuration preserves page/program/cohort, canonical course, named staff, approved deterministic temporary doctor identities, and only explicitly numbered offering-scoped sections.

The pasted transcription does not associate individual class entries with day/start/end values. Therefore the importer imports master relationships but defers all weekly `Schedule` rows until those values are available in the source. Room names are descriptive timetable metadata only; they are never converted to `AttendanceLocation` records. Student section membership and student-to-course offering enrollment remain uncreated unless explicitly proven by another source.
